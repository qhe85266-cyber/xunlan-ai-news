# Xunlan AI · 讯澜 AI

![Original Xunlan AI brand illustration](assets/brand-cover.jpg)

An AI news and daily digest demo for product managers, derived from [KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT). This repository adds nine product-oriented sources and a distinct display identity. The upstream engine provides collection, selection, event grouping and publication.

This is a customized demonstration, not an independently authored engine or the official AIHOT service. The original [LICENSE](LICENSE) and [NOTICE](NOTICE) are retained. The cover is an AI-generated brand illustration, not a running UI screenshot or performance evidence.

Read the [Chinese project guide](README.md), [deployment guide](docs/deploy.md) and [branding record](BRANDING.md). Internal package names and existing MCP tool names are retained for compatibility. Historical screenshots may display the previous identity.
